# Программная система автоматического подбора параметров кодирования видео

## Требования

Для работы программы необходимы:

* Python версии 3.11 или выше;
* FFmpeg (должен быть доступен из системной переменной `PATH`);
* SQLite3;
* Git.

## Установка

Клонировать репозиторий:

```bash
git clone <адрес_репозитория>
cd <имя_репозитория>
```

Создать виртуальное окружение.

Для Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Для Windows:

```powershell
python -m venv .venv
.venv\Scripts\activate
```

Установить необходимые зависимости:

```bash
pip install -r requirements.txt
```

Убедиться, что FFmpeg установлен и доступен для запуска:

```bash
ffmpeg -version
ffprobe -version
```

## Запуск программы

Для запуска приложения выполнить команду:

```bash
python main.py
```

или

```bash
python3 main.py
```

в зависимости от конфигурации системы.

## Первый запуск

При первом запуске приложение проверяет наличие файла базы данных, путь к которому указан в переменной `DB_PATH` файла `db_engine.py`.

Если база данных отсутствует, она будет создана автоматически.

## Авторизация

Перед началом работы необходимо выполнить вход в систему.

Для нового пользователя необходимо зарегистрировать учетную запись, указав логин и пароль.

После успешной регистрации или авторизации становится доступен основной функционал программы.

Пароли пользователей сохраняются в базе данных в виде хэш-сумм.

## Порядок работы

1. Выполнить вход в систему.
2. Выбрать видеофайл для анализа.
3. Запустить анализ содержимого видео.
4. Дождаться завершения извлечения признаков.
5. Выбрать параметры кодирования вручную либо загрузить ранее сохраненный пресет.
6. Запустить процесс сжатия видео.
7. После завершения процесса ознакомиться с результатами кодирования и значением метрики схожести исходного и полученного видео.

## Работа с пресетами

Программа поддерживает сохранение пользовательских пресетов параметров кодирования.

Каждый пресет содержит:

* название;
* описание;
* значение CRF;
* значение параметра Preset;
* значение AQ Mode;
* количество B-Frames.

Все пресеты привязаны к учетной записи пользователя. При загрузке отображаются только пресеты текущего пользователя.

## Используемые технологии

В процессе работы программа использует:

* Python;
* Tkinter;
* FFmpeg;
* ffprobe;
* SQLite3;
* OpenCV;
* NumPy.

## Примечания

* FFmpeg должен быть установлен и доступен из командной строки.
* Для корректной работы рекомендуется использовать видеофайлы в форматах, поддерживаемых FFmpeg.
* Время анализа и кодирования зависит от разрешения, длительности и сложности видеоконтента.
* Удаление файла базы данных приведет к удалению всех зарегистрированных пользователей и сохраненных пресетов.
* Прерывание процесса кодирования может привести к сохранению временных файлов.
